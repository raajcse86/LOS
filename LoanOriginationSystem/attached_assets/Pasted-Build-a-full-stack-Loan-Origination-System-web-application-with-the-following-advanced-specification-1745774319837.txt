Backend:

Use python and flask for backend.

RESTful APIs for all front-end communication.

Business Logic:

Sales user fills Borrower + Employment → moves to PreApplication milestone.

Sales user adds Property info → moves to Submitted milestone.

Processor user uploads the employment docs and personal IDs and payslip document, save these document in database →  IRR milestone.

Underwriter user pulls the document from database extracts the document content, checks the compliance score and if the score is above 90% approve the loan, then create a detailed report and save to database → 
if approved, FRR milestone.

Closer user adds closing fees details and prepare closing document report and saves to database → Closing Docs Generated milestone.

Manager user ensures consent documents are signed → Funds Disbursed milestone.

No need to have any authentication mechanism either to login and to invoke backend api as well.

Roles: Sales, Processor, Underwriter, Closer, Manager (role-based access control).
